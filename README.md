# Grindstone Coffee Co. – Sales Performance Dashboard

**Tools:** Power BI | DAX | Data Modelling

### Business Question
How is Grindstone Coffee Co. performing across locations, products, and time periods, and where are the biggest opportunities to grow revenue and average order value?

### What I did
- Designed and built a multi-page interactive Power BI dashboard analysing $700K+ in sales data
- Created a clean data model with key DAX measures
- Developed visuals covering monthly revenue trends, location performance, product & category breakdown, hourly order patterns, and top-selling products
- Added clear written insights and actionable recommendations directly on the report pages

### Key Insights & Recommendations
- Revenue grew strongly from $76K in January to $167K in June
- Average Order Value is only $4.70 — a clear opportunity for upselling and combo deals
- Orders peak between 8–11 am, making this the ideal window to promote higher-margin items
- The three main locations perform almost equally, with no single weak store
- Coffee dominates revenue, with large sizes and organic/specialty products leading the top sellers

### Outcome
Delivered a clear, stakeholder-ready dashboard that highlights practical actions to increase both revenue and average order value.
